# Лабораторная работа 2

**Выполнил:** Бородин Максим, группа K3341.

## Цель

Сравнить потоки, процессы и `asyncio` на двух задачах: подсчёте суммы чисел от 1 до `10^13` и загрузке нескольких веб-страниц.

## Реализация

Для суммы диапазон делится на четыре части. Каждая подзадача вызывает `calculate_sum()`, после чего частичные результаты складываются. Использована формула арифметической прогрессии, иначе перебор `10^13` чисел занял бы непрактично много времени.

Для парсинга каждая реализация одновременно загружает три URL, получает тег `<title>` и записывает его в таблицу `parsed_pages` базы `pages.db`. Во всех трёх файлах есть требуемая функция `parse_and_save(url)`.

| Подход | Механизм | Основное применение |
|---|---|---|
| `threading` | несколько потоков с общей памятью | блокирующие I/O-операции |
| `multiprocessing` | отдельные процессы | CPU-bound вычисления |
| `asyncio` | event loop и корутины | большое число сетевых запросов |

## Результаты

| Подход | Сумма | Парсер |
|---|---:|---:|
| threading | 0.000185 с | 0.315 с |
| multiprocessing | 0.078173 с | 0.434 с |
| asyncio | 0.000089 с | 1.037 с |

Все варианты суммы возвращают `50000000000005000000000000`. Формула выполняется почти мгновенно, поэтому в этом тесте в основном сравниваются накладные расходы на создание исполнителей. Для сетевого парсинга потоки и `asyncio` полезны, потому что перекрывают ожидание HTTP-ответов. Конкретные сетевые значения зависят от соединения и при новом запуске изменятся.
