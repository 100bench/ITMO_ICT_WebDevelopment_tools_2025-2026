# Лабораторная работа 3

**Выполнил:** Бородин Максим, группа K3341.

## Цель

Упаковать FastAPI, парсер и базу данных в Docker, организовать прямой вызов парсера и фоновую обработку через очередь Celery.

## Сервисы

| Сервис | Назначение |
|---|---|
| `api` | принимает запрос клиента |
| `parser` | загружает страницу, извлекает `<title>`, пишет в PostgreSQL |
| `db` | хранит таблицу `parsed_pages` |
| `redis` | брокер и хранилище результата Celery |
| `worker` | выполняет фоновые задачи |

## Прямой вызов

`POST /parse` принимает URL. API отправляет HTTP-запрос сервису `parser`, ждёт результат и возвращает его клиенту.

```text
клиент -> api -> parser -> сайт -> PostgreSQL
```

## Вызов через очередь

`POST /parse/async` создаёт Celery-задачу и сразу возвращает `task_id` со статусом 202. Worker получает задачу из Redis и обращается к parser-service. Состояние проверяется через `GET /tasks/{task_id}`.

```text
клиент -> api -> Redis -> worker -> parser -> сайт -> PostgreSQL
```

Compose создаёт общую сеть автоматически, поэтому контейнеры обращаются друг к другу по именам сервисов: `parser`, `redis`, `db`. PostgreSQL хранит данные в named volume `postgres_data`.
